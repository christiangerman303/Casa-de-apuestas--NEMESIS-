# Nemesis - Fictional Betting House


Educational project developed by Cristian.


## Overview and Features


Nemesis is an educational web platform designed as a fictional betting house where **no real money is bet**. Its main goal is to apply web concepts such as HTML5 semantics and responsive design.


### Main Sections
- **Sports:** Informational cards for Football, Basketball, Tennis, and Esports.
- **Odds:** Interactive table with fictional odds for upcoming events.
- **How It Works:** Step-by-step guide on how the platform operates.
- **Gallery:** Visual selection of different sports disciplines.
- **Responsible Gambling:** Awareness guidelines and age indication (+18).


## Technologies Used


- **HTML5:** Semantic structure (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`).
- **CSS3:** Custom stylesheet with a *Mobile-First* approach and breakpoints (*Media Queries*) at `768px` and `992px` for *Responsive* design.
- **Icons and Fonts:** Google Material Symbols Outlined and Google Fonts.
