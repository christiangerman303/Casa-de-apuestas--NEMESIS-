# Nemesis - Casa de apuestas ficticia


Proyecto educativo desarrollado por Cristian.


## Descripción general y características


Nemesis es una plataforma web educativa diseñada como una casa de apuestas ficticia en la que **no se apuesta dinero real**. Su objetivo principal es aplicar conceptos web como semántica HTML5 y diseño adaptativo.


### Secciones principales
- **Deportes:** Tarjetas informativas de Fútbol, Baloncesto, Tenis y Esports.
- **Cuotas:** Tabla interactiva con cuotas ficticias para eventos próximos.
- **Cómo funciona:** Guía paso a paso sobre el funcionamiento de la plataforma.
- **Galería:** Selección visual de diferentes disciplinas deportivas.
- **Juego Responsable:** Pautas de concienciación e indicación de edad (+18).


## Tecnologías utilizadas


- **HTML5:** Estructura semántica (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`).
- **CSS3:** Hoja de estilos personalizada con enfoque *Mobile-First* y puntos de interrupción (*Media Queries*) a `768px` y `992px` para diseño *Responsive*.
- **Iconos y Fuentes:** Google Material Symbols Outlined y Google Fonts.

1. **Clonar o descargar** el repositorio en tu equipo.
2. Asegurarse de mantener la estructura de carpetas (`css/` e `img/`).
3. Abrir el archivo `index.html` en cualquier navegador web moderno para visualizar el proyecto.
