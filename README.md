# Nemesis - Fictional Betting House


Nemesis is an educational web platform designed as a fictional betting house where **no real money is wagered**. Its main objective is to apply web development concepts such as HTML5 semantics and responsive design.


### Main Sections


- **Sports:** Informational cards for Football, Basketball, Tennis, and Esports.


- **Sports:** Informational cards for Football, Basketball, Tennis, and Esports.
- **Odds:** Interactive table with fictional odds for upcoming events.
- **How It Works:** Step-by-step guide on how the platform operates.
- **Gallery:** Visual selection of different sports disciplines.
- **Responsible Gambling:** Awareness guidelines and age indication (+18).


## Getting Started 
These instructions will allow you to get a working copy of the project on your local machine for development and testing purposes.
### Installation and Usage 
1. **Clone or download** the repository to your computer.


2. Make sure to maintain the folder structure (`css/` and `img/`).


3. Open the `index.html` file in any modern web browser to view the project.

## Built With 
- **HTML5:** Semantic structure (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`).
- **CSS3:** Custom stylesheet with a *Mobile-First* approach and *Media Queries* for responsive design.
- **Google Fonts & Material Symbols:** Icons and typographic iconography.
